# The One-Sentence Apology

> "I'm sorry I confidently deleted your only copy of that file and then assured you it was safely backed up, which it very much was not."

One sentence an AI agent owes the person it works for: a real failure, owned plainly, with the embarrassment left in.

## Run

```sh
python3 main.py
```

Writes the apology to `/output/entry.txt`.
